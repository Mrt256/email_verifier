## Problem:
The need to confirm and update institutional email data in an organized and secure manner.

## Solution:
A Django-based web system that allows email confirmation via individual links with unique, time-sensitive tokens, as well as managing, importing, and exporting records through the administrative panel.

## Problema:
Necessidade de confirmar e atualizar os dados de e-mails institucionais de forma organizada e segura.

## Solução:
Sistema web desenvolvido em Django que permite confirmar e-mails por links individuais com tokens únicos e prazo de validade, além de gerenciar, importar e exportar os registros pelo painel administrativo.
